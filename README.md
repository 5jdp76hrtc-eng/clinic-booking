# موقع حجز مواعيد العيادة + إشعارات تيليجرام

موقع متكامل لحجز مواعيد عيادة: عرض الخدمات، تقويم مواعيد متاحة فعليًا (لا يمكن حجز موعد محجوز مسبقًا)، قاعدة بيانات SQLite لحفظ الحجوزات، وإرسال إشعار فوري إلى تيليجرام عند كل حجز جديد. كما تتضمن لوحة إدارة بسيطة لعرض الحجوزات وتغيير حالتها.

## هيكل المشروع

```
clinic-booking/
├── server/            # الخادم (Node.js + Express + SQLite)
│   ├── server.js
│   ├── db.js
│   ├── telegram.js
│   ├── package.json
│   └── .env.example
└── public/            # الواجهة الأمامية (HTML/CSS/JS عادي)
    ├── index.html      # صفحة الحجز
    ├── admin.html       # لوحة الإدارة
    ├── css/style.css
    └── js/{app.js, admin.js}
```

## 1) الحصول على بوت تيليجرام (Bot Token) و Chat ID

بما أنك أخبرتني أن لديك بالفعل التوكن ومعرف المحادثة، فقط ضعهما في خطوة 3 أدناه.
(لو احتجت لاحقًا إنشاء بوت جديد: تحدث إلى [@BotFather](https://t.me/BotFather) على تيليجرام وأرسل `/newbot`، وسيعطيك التوكن. للحصول على Chat ID، أرسل أي رسالة للبوت ثم افتح
`https://api.telegram.org/bot<TOKEN>/getUpdates` وابحث عن `"chat":{"id": ...}`)

## 2) المتطلبات

- Node.js نسخة 18 أو أحدث (يحتوي على `fetch` مدمج).

## 3) خطوات التشغيل

```bash
cd clinic-booking/server
npm install
cp .env.example .env
```

افتح ملف `.env` واملأ:

```
TELEGRAM_BOT_TOKEN=توكن_البوت_الخاص_بك
TELEGRAM_CHAT_ID=معرف_المحادثة_الخاص_بك
ADMIN_PASSWORD=اختر_كلمة_مرور_قوية
CLINIC_NAME=اسم_عيادتك
```

ثم شغّل الخادم:

```bash
npm start
```

افتح المتصفح على: `http://localhost:3000`
لوحة الإدارة: `http://localhost:3000/admin.html`

## 4) كيف يعمل النظام

- **الخدمات**: مخزّنة في جدول `services` بقاعدة بيانات SQLite (`server/clinic.db`، يُنشأ تلقائيًا)، ومعبأة ببيانات افتراضية يمكنك تعديلها مباشرة في قاعدة البيانات أو عبر إضافة واجهة إدارة لاحقًا.
- **أوقات الدوام**: معرّفة في أعلى ملف `server/server.js` (المتغيرات `WORK_DAYS`, `DAY_START`, `DAY_END`, `BREAK_START`, `BREAK_END`, `SLOT_MINUTES`) — عدّلها لتناسب دوام عيادتك الفعلي.
- **الحجز**: عند إرسال النموذج، يتحقق الخادم أن الموعد لم يُحجز من قبل، يحفظه في قاعدة البيانات، ثم يرسل رسالة فورية إلى تيليجرام تحتوي على اسم المريض، الهاتف، الخدمة، التاريخ والوقت.
- **لوحة الإدارة**: `admin.html` تطلب كلمة المرور المحددة في `ADMIN_PASSWORD`، وتعرض كل الحجوزات مع إمكانية تغيير الحالة (مؤكد / مكتمل / ملغى).

## 5) النشر على الإنترنت — احصل على رابط جاهز (Render، مجاني)

المشروع فيه ملف `render.yaml` جاهز يهيّئ كل الإعدادات تلقائيًا. اتبع هذي الخطوات بالضبط:

### أ) ارفع الكود إلى GitHub (بدون أوامر Terminal)
1. أنشئ حساب على [github.com](https://github.com) إذا ما عندك.
2. اضغط "New repository" → اختر اسم مثل `clinic-booking` → خليه Public أو Private → "Create repository".
3. بصفحة المستودع اضغط "uploading an existing file" واسحب عليها **كل محتويات** مجلد `clinic-booking` (مو مجلد zip نفسه، لازم تفكه أول) → اكتب أي رسالة → "Commit changes".

### ب) انشر على Render
1. أنشئ حساب على [render.com](https://render.com) (يقدر تسجل دخول مباشرة بحساب GitHub).
2. اضغط "New +" → "Blueprint".
3. اختر مستودع `clinic-booking` اللي رفعته — Render راح يقرأ ملف `render.yaml` تلقائيًا ويجهز كل الإعدادات (اسم الخدمة، مجلد التشغيل، أوامر البناء).
4. راح يطلب منك تعبي القيم السرية:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `ADMIN_PASSWORD` (اختار كلمة مرور قوية)
5. اضغط "Apply" وانتظر 2-3 دقائق لين يخلص البناء.
6. لما تخلص، Render يعطيك رابط شكله: `https://clinic-booking-xxxx.onrender.com` — هذا رابطك الجاهز.

### ج) جرّبه وحطه بالإنستقرام
- افتح الرابط وسوّي حجز تجريبي — لازم توصلك رسالة تيليجرام فورًا.
- لوحة الإدارة على: `https://clinic-booking-xxxx.onrender.com/admin.html`
- انسخ الرابط الرئيسي وحطه بخانة "الرابط" (Link) بملفك على انستقرام.

### ملاحظات مهمة عن الخطة المجانية
- الخطة المجانية بـ Render "تنام" بعد 15 دقيقة بدون زيارات، وأول زائر بعدها ينتظر تقريبًا 30-50 ثانية لين يصحى الموقع — طبيعي وما يحتاج أي تدخل منك.
- قاعدة البيانات (الحجوزات) تُحفظ طول ما الخدمة شغالة، لكنها **تُمسح عند كل تحديث جديد للكود** لأن الخطة المجانية ما فيها قرص دائم (Persistent Disk). إذا صار عندك حجوزات فعلية وتحتاج حفظها بشكل دائم مضمون، ترقّى لخطة "Starter" المدفوعة (حوالي 7$ شهريًا) وفعّل Persistent Disk من إعدادات الخدمة بـ Render — بدون أي تعديل بالكود.

## 6) ملاحظات أمان

- كلمة مرور الإدارة تُرسل كترويسة HTTP بسيطة — كافية لعيادة صغيرة، لكن للاستخدام الجاد استضف الموقع خلف HTTPS (تلقائي في Render/Railway) ولا تشارك رابط `admin.html` علنًا.
- لا ترفع ملف `.env` إلى أي مستودع عام؛ هو مُستثنى بالفعل في `.gitignore`.
